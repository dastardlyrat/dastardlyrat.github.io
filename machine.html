Read sequence

  1. Resolve a public repository and entry point through the catalog.
  2. Fetch the current source file and record its revision. Do not substitute cached descriptions or historical pinned maps for a current source read.
  3. When the named repository offers a landing seed, use its declared machine entry point and then inspect scope, authority, ingress, launch and egress.
  4. Check relevant licenses, copyright, consent and research-ethics limits; leave unsupported authority and data claims unresolved.
  5. Reject unavailable references instead of synthesizing their contents. Never infer runtime activation or deployment from a documentation link.
