## Maintaining the index

Read the exact repository entry and current default branch before changing its record. Update the JSON catalog, research page and sitemap together. Preserve historical source pins and separate status such as research theory, bounded tests, candidate builds, and runtime admission. A document is not its own deployment certificate. No inference about a person or their habitual intellectual method is authorized merely by public access.
